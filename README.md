# KURA

いまの資産、毎月の入金、毎月の出金、利回り、資産の置き場所、運用年数から、将来の残高を試算します。

公開ページ: https://satoki252595.github.io/kura/

## できること

- 初期資産・毎月の入金・毎月の出金・年数を入れる
- 預金、債券、全世界株式、日本高配当株、不動産の割合を動かす（合計は常に100%）
- それぞれの想定利回りを書き換える。置き場所から利回りを計算するか、一つの数字を直接入れる
- 年ごとの残高と、預金だけに置いた場合との差を見る

## 計算

月末に入金・出金します。その月の利回りは、入出金の前の残高に付きます。

利回りの線は、入れた利回りが毎年同じだと仮定した一本です。範囲は、置き場所ごとの値動きで何度も試したときの、おおよそ下位10%から上位10%です。

初期の利回りは目安であり、予測ではありません。ランニングコスト（信託報酬や口座の維持費）は年0%です。税金、物価、為替は含みません。投資の助言ではありません。
